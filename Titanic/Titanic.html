Understanding the supplied Titanic solution¶

The source uses four text inputs: PClass, Gender, Sibling and Embarked. LabelEncoder converts their fixed category lists and the Survived target to integers. Its first 80 records train an RBF SVC (gamma='auto', random_state=0), and the last 20 evaluate it. New passenger inputs must reuse those encoders in the same feature order. The saved model supports prediction without training again.

This notebook preserves those data, encodings, split and SVC settings. It adds data checks, a model/encoder bundle, a majority baseline, per-row error review and Abeera's Streamlit app. The original instructor notebook is executed separately in the workspace reference folder. These are 100 simplified teaching records, not the full historical Titanic dataset.

Step 5: Label encoding¶

5.1 Fit encoders; 5.2 encode output; 5.3 encode inputs¶

The category vocabularies are fixed by the dataset definitions, not learned from the held-out labels. LabelEncoder sorts labels. For Titanic this means Sibling codes are One=0, Three=1, Two=2, Zero=3; they are not sibling counts. For Heart Disease cp codes 1-4 map to 0-3, and num > 0 supplies the binary target. Numeric measurements are not converted into arbitrary category labels. These encoders will be saved for inference.

inference_source = '"""Validation and inference shared by the notebook and web interface."""\nimport math\nimport pandas as pd\n\n\ndef encode_case(values, bundle):\n    if set(values) != set(bundle["features"]):\n        raise ValueError("Supply exactly the four declared input attributes.")\n    frame = pd.DataFrame([values], columns=bundle["features"])\n    if bundle["task"] == "Heart_Disease":\n        bounds = {"age": (1, 120), "thalach": (30, 250), "oldpeak": (0, 10)}\n        for field, (low, high) in bounds.items():\n            value = float(values[field])\n            if not math.isfinite(value) or not low <= value <= high:\n                raise ValueError(f"{field} must be between {low} and {high}.")\n            if field != "oldpeak" and not value.is_integer():\n                raise ValueError(f"{field} must be a whole number.")\n            frame[field] = value\n    for field, encoder in bundle["encoders"].items():\n        if values[field] not in encoder.classes_:\n            raise ValueError(f"Unknown category for {field}.")\n        frame[field] = encoder.transform(frame[field])\n    return frame\n\n\ndef predict_case(values, bundle):\n    return int(bundle["model"].predict(encode_case(values, bundle))[0])\n'

Learning reflection¶

The important connection is that deployment must apply exactly the representation used during training. Saving only an estimator would leave the app dependent on manually recreating its encoders and feature order. Saving them together and verifying reload predictions makes the training-to-application path reproducible. The four ML phases are demonstrated without mistaking a small held-out score for broad real-world validity.
